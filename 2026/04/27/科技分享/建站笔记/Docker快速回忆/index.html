Docker快速回忆

一、核心概念

  • 容器（Container）：包含项目代码、项目环境和文件系统，可以理解为镜像的解压；
  • 镜像（Image）：可以理解为一个项目的源码及环境的压缩包，但不包含操作系统；
  • 仓库（Registry）：存储和分发镜像的平台，官方镜像仓库Docker Hub；
  • Dockerfile：描述如何自动构建镜像，包括基础镜像构建顺序、依赖软件安装和运行指令等；

三、基本命令

镜像命令

  1. 查看所有镜像：sudo docker images;
  2. 删除指定镜像：sudo docker rmi IMAGEID;
  3. 拉取指定镜像：docker pull docker.n8n.io/n8nio/n8n:latest
    • docker.n8n.io：n8n私有docker仓库地址；
    • n8nio：namespace命名空间，也就是作者名；
    • n8n：镜像名；
    • latest：版本号；

容器命令

  1. 运行一个容器：docker run n8n；
    • -d：后台运行，只显示容器ID；
    • -p 80:81：端口映射，冒号前80是宿主机的端口，冒号后81是容器内的端口；
    • -v 宿主机目录:容器内目录：挂载卷，共享文件夹，操作会同步，数据可持久化保存在宿主机；
    • --name my_n8n：自定义容器名，具有唯一性，可当作容器ID使用；
  2. 查看正在运行的容器：docker ps，备注：-a：可以查看停止运行的容器；
  3. 删除容器：sudo docker rm -f 容器ID；备注：-f：强制删除正在运行的容器；
  4. 挂载卷：sudo docker volume create nginx_html；创建了一个名为nginx_html的挂载卷，真实位置可通过命令sudo docker volume inspect nginx_html来查看，还有些其他命令：
    • sudo docker volume list：查看所有卷；
    • sudo docker volume rm nginx_html：删除指定卷；
    • sudo docker volume prune -a：删除所有未使用的卷；
