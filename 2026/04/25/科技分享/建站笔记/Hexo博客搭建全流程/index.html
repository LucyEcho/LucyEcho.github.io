  1. git 管理工具（下载官网）；
  2. node.js（下载地址），需要npm（[可以换源](npm config set registry https://registry.npmmirror.com)）工具去下载Hexo；
  3. github 账号（官网地址）；
  4. Hexo CLI工具：npm install -g hexo-cli
